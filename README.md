## About

I'm a software engineer from **Castelo Branco, Portugal**, with an MSc in Telecommunications and Informatics Engineering from **Instituto Superior Técnico** (Lisbon).

I spent several years at **CERN** building recruitment, planning and warehouse software, with earlier work at **Bullray-CIT** and **IST/INESC**. These days most of my side projects orbit real-time graphics: a Vulkan engine, signed distance fields, ray marching and procedural worlds — alongside AI tooling, VR music and whatever else seems worth compiling.

I like low-level rendering as much as I like shipping a clean web UI, and I tend to document things by building a demo for them.
